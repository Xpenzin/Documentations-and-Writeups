## Hey, welcome 
 
This is just where I dump my HTB writeups and whatever other security stuff I'm learning. Don't expect polished, professional documentation...
 
### What's in here?
 
Each machine gets its own folder with a write-up (`.md`) and a `Pics/` folder for screenshots. I try to walk through my actual thought process — recon, the dumb guesses, the stuff that didn't work, and eventually the exploit/privesc that did.
 
### Heads up
 
- I'm still new to this, so don't take anything here as gospel. If something's wrong or there's a better way, feel free to open an issue.
- No flags posted, obviously (HTB policy).
- Formatting gets sloppier the deeper into a box I get. That's not a bug, that's just what 2am privesc rabbit holes do to a man.

### Why?
 
Mostly for myself, so I can look back and see how far I've come (or laugh at past me). If it helps anyone else learning this stuff too, even better.
 
Enjoy the chaos.
